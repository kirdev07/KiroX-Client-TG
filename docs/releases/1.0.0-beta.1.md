## KiroX 1.0.0-beta.1 — первая бета

Независимый клиент Telegram на TDLib. Это **бета**: основные вещи работают, но многое ещё в разработке, возможны ошибки.

### Что работает
- Вход по номеру, коду и паролю 2FA, вход по QR-коду, выход.
- Чаты и архив: список, закрепление, архивация, отметка «непрочитано», истории в шапке.
- Переписка: отправка, ответ, редактирование, удаление, пересылка, копирование текста, фото и документы.
- Избранное (Saved Messages).
- **Голосовые и видеозвонки** через собственный движок на tgcalls и WebRTC: шифрование, камера, переключение камеры, микрофон, динамик и трубка.
- Звонок продолжается в фоне с уведомлением «Идёт звонок». Входящий, пока приложение свёрнуто, приходит полноэкранным уведомлением. У уха экран гаснет.
- Контакты: карточка с «Написать / Звонок / Видео», сначала те, кто в сети, затем по алфавиту, поиск по имени, @нику и номеру, добавление контакта по номеру, журнал звонков с фильтрами.
- Кнопки звонка в шапке личного чата.
- Кастомизация: 4 тёмные темы, форма пузырей, обои, размер текста и плотность чата, анимации (Хэллоуин, Зима, Новый год, «Авто по дате»), лёгкий режим для слабых телефонов.
- Автообновление из GitHub Releases с проверкой SHA-256, пакета, подписи и версии.

### Что ещё не готово — 21 пункт
**Настройки (8):** Чаты и папки · Уведомления · Конфиденциальность · Данные и память · Устройства · Telegram Premium · Возможности KiroX · Дополнительно — пока показывают «В разработке».

**Профиль и аккаунт (5):** редактирование профиля · смена фото · несколько аккаунтов · поиск по настройкам · QR-код профиля.

**Чаты (5):** создание групп · создание каналов · секретные чаты · меню чата (⋮) · запись голосовых сообщений.

**Прочее (3):**
- публикация своих историй и публикаций в профиле;
- входящие звонки и сообщения, когда приложение **полностью выгружено** из памяти: Telegram не отправляет push в Firebase для неофициальных клиентов, вариант через UnifiedPush/ntfy ещё проверяется;
- групповые звонки и демонстрация экрана.

### Известные ограничения
- Только Android на arm64 (почти все телефоны последних лет), Android 6.0 и новее.
- На Xiaomi/MIUI для звонков в фоне включите для KiroX «Автозапуск» и «Без ограничений» в экономии батареи.

### Установка
Скачайте `KiroX-1.0.0-beta.1.apk` ниже и установите. Следующие версии приложение найдёт само: **Настройки → Обновления**.
