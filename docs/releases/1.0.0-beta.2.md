## KiroX 1.0.0-beta.2

Вторая бета: исправления по аудиту и три новых функции. Обновление ставится поверх 1.0.0-beta.1, вход и настройки сохраняются.

### Новое
- **Уведомления о новых сообщениях** — по одному на чат, с именем и текстом, кнопка «Прочитано». Чаты без звука не уведомляют. Работают, пока приложение свёрнуто (не выгружено системой).
- **Голосовые сообщения** — запись по нажатию на микрофон, отправка, воспроизведение входящих.
- **Меню чата (⋮)** — без звука, поиск по переписке, очистить историю, удалить чат / покинуть группу.
- **Настройки → Устройства** — все сеансы аккаунта, завершение одного или всех остальных.

### Исправлено
- Анимация в шапке замирает через 20 секунд без касаний: в простое расход процессора упал с ~36% до 0%.
- Звонок сразу после запуска приложения больше не «соединяется» без звука.
- Исключён двойной запуск TDLib при одновременном push и открытии приложения.
- В фоне статус «в сети» теперь сбрасывается — «был(а) в…» показывается честно.

### Ещё не готово — 18 пунктов
**Настройки (7):** Чаты и папки · Уведомления · Конфиденциальность · Данные и память · Telegram Premium · Возможности KiroX · Дополнительно.
**Профиль и аккаунт (5):** редактирование профиля · смена фото · несколько аккаунтов · поиск по настройкам · QR-код профиля.
**Чаты (3):** создание групп · создание каналов · секретные чаты.
**Прочее (3):** публикация историй · входящие при **полностью выгруженном** приложении · групповые звонки и демонстрация экрана.

### Известные ограничения
- Только Android 10–17, 64-бит (arm64).
- На Xiaomi/MIUI для звонков и уведомлений в фоне включите для KiroX «Автозапуск» и «Без ограничений» в экономии батареи.
- Реакции и отправка видео пока недоступны.
