## KiroX 1.0.0-beta.3

Третья бета. Обновление ставится поверх предыдущей, вход и настройки сохраняются.

### Новое
- **Реакции** ❤ 👍 🔥 😁 👏 — долгое нажатие на сообщение; повторное нажатие снимает.
- **Отправка видео** — «+» → «Фото и видео».
- **Редактирование профиля** — имя, фамилия, «о себе», имя пользователя.
- **Смена фото профиля** — из галереи (Настройки, Профиль).
- **Создание групп и каналов** — «Новое сообщение» → «Создать группу» / «Создать канал».

### Исправлено
- Экран звонка показывает «Переподключение…» при обрыве, «плохая связь» и выключенный микрофон собеседника.
- Приложение больше не пытается при каждом запуске регистрироваться в Firebase после отказа Telegram.

### Ещё не готово — 14 пунктов
**Настройки (7):** Чаты и папки · Уведомления · Конфиденциальность · Данные и память · Telegram Premium · Возможности KiroX · Дополнительно.
**Аккаунт (3):** несколько аккаунтов · поиск по настройкам · QR-код профиля.
**Чаты (1):** секретные чаты.
**Прочее (3):** публикация историй · входящие при **полностью выгруженном** приложении · групповые звонки и демонстрация экрана.

### Известные ограничения
- Только Android 10–17, 64-бит (arm64).
- На Xiaomi/MIUI для звонков и уведомлений в фоне включите для KiroX «Автозапуск» и «Без ограничений» в экономии батареи.
