# UI/UX-аудит Fusion

Анализ по исходному коду и `design-reference/` (скриншоты на устройстве в этой сессии не снимались → визуальные выводы о «как выглядит» помечены [?]). Нижняя панель — отдельный файл `BOTTOM_NAVIGATION_AUDIT.md`.

Реальный режим сейчас содержит только экран входа и список чатов; остальные экраны существуют **только в DEMO** (`DemoMainScreen.kt`). Аудит экранов ниже относится к DEMO-реализации как к прототипу будущего UI.

## 2. Контакты
- Поиск — поле под вкладками, а иконка поиска в шапке показывает тост «Поле поиска находится под вкладками» — **дубль/ложная кнопка** [П].
- Строка: две иконки 48 dp (сообщение, звонок) на каждой строке — визуальный шум; лучше тап = профиль/чат, звонок в профиле или свайпе.
- Статус — свободный текст; нет «в сети» выделения.
- «Пригласить друзей» — `OutlineButton` прибит под списком, при клавиатуре может перекрываться [?]. Текст инвайта без ссылки.
- Профиль контакта — не открывается (тап по строке ничего не делает) [П].
- Добавление контакта — DEMO-диалог с полем «Статус», которого в Telegram нет [П].

## 3. Звонки
- Находятся во вкладке внутри «Контактов» — ок для минимализма, но фильтр-чипы дублируют вкладки по смыслу.
- Фильтры «Все / Пропущенные / Входящие / Исходящие» ✅, сохраняются в DataStore ✅.
- Время — только `HH:mm`, без даты: звонок недельной давности неотличим [П] 🟠. Нужны «Сегодня / Вчера / дата» и группировка.
- Нет длительности, нет типа (аудио/видео), нет группировки повторных звонков.
- Повторный вызов — DEMO-диалог «добавить в журнал». Реальные звонки требуют VoIP-стек (см. TDLIB_STATUS) — **не обещать видео/групповые**.
- Цвет пропущенных `#FF7770` — единственный цветной акцент, согласовать с токеном `danger`.

## 4. Настройки
- Блок профиля (`CenterIdentity`) — **захардкожен** «Кирилл», «@username» [П] 🔴 при переносе в реальный режим.
- Кнопка «Переключить аккаунт» показывает тост; рядом кнопка «сезонные эффекты» с иконкой Stories — неочевидно [П].
- 11 пунктов, работает только «Кастомизация» (1 переключатель). Остальные — тост [П].
- Дублирование: «Возможности KiroX» / «Дополнительно» / «Кастомизация» пересекаются по смыслу; «Обновления» и «О KiroX» можно объединить [П].
- Нет поиска (заглушка), нет групп/секций — плоский список.
- Отсутствуют: Выход из аккаунта, Язык, Тема (AMOLED/Graphite).

## 5. Мой профиль
- Дублирует блок профиля из «Настроек» (аватар, имя, кнопки редактирования/аккаунтов) [П] — см. концепцию 4 в аудите нижней панели.
- «О себе: Создаю KiroX», «Дата рождения: Не указана» захардкожены [П].
- Медиа/Файлы/Ссылки/Истории — чипы + одна карточка «Данные появятся после подключения TDLib».
- Горизонтальный свайп по чипам конфликтует с глобальным свайпом вкладок (обрабатывается `consume`, но корневой детектор всё равно на родителе) [?].
- Аккаунты: bottom sheet с DEMO-аккаунтами; добавление — заглушка.

## 6. Экран чата (DEMO)
Самый проработанный экран: ответы, редактирование, реакции, поиск, закрепление, черновики, меню. Недостатки: `Configuration.screenWidthDp` (lint), O(n²) поиск закрепления, Flow без `remember`, вставка эмодзи `+2` к selection ломается на составных эмодзи [П], отсутствие пагинации и `reverseLayout` (для длинной истории придётся прокручивать к концу) [П].

## 8. Производительность UI
| Проблема | Где | Крит. |

| Flow без `remember`, O(n²) | `ChatScreen.kt` | 🟡 |
| Полная пересортировка чатов на каждый update | `TdlibClientManager.publishChats` | 🟠 |
| Нет загрузчика изображений (Coil) и даунсемплинга — понадобится для аватаров/медиа | — | 🟠 |
