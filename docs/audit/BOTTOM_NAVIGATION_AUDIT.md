# Аудит нижней панели

В проекте **две независимые реализации** [П]:
- `ui/home/DemoMainScreen.kt` → `BottomDock` (DEMO, рабочее переключение 4 вкладок);
- `ui/home/TelegramMainScreen.kt` → `RealBottomDock` (реальный режим, вкладки кроме «Чаты» — заглушка-тост).

Оценка состояния: **4/10** (критерии: визуальная согласованность, корректные insets, обратная связь, доступность, единая реализация). Визуальная идея (монохром, 4 раздела, подписи) хорошая; реализация сырая.

## 1. Проверка по пунктам

| # | Пункт | DEMO `BottomDock` | Real `RealBottomDock` | Статус |

Дополнительно [П]:
- `indication = null` в DEMO → **нет визуального отклика на нажатие** (ripple отключён).
- Скрытый жест: долгое нажатие на «Профиль» открывает выбор аккаунтов — не обнаруживаемо, нет семантики `onLongClickLabel`.
- `IconGlyph(tab.icon, tab.title, …)` + `Text(tab.title)` → TalkBack читает название дважды; нет `Modifier.selectable(role = Role.Tab)` / `selected`-семантики.
- Порядок вкладок «Контакты · Чаты · Настройки · Профиль»: «Чаты» (основной раздел) не первый; «Настройки» и «Профиль» дублируют друг друга (оба содержат блок профиля, см. UI_UX_AUDIT).
- Фон `0xFF040404` (DEMO) / `0xFF070707` (Real) — почти чёрный, отличный от `Color.Black` фона экрана → видимая «полоса» на AMOLED.

## 2. Концепции улучшения (не внедрены, требуют согласования)

Общая основа для всех: один компонент `FusionBottomBar`, верхний hairline 0.5–1 dp вместо рамки, `windowInsetsPadding(navigationBars)` внутри с фоном на всю высоту, высота контента 64 dp, иконки 24 dp, подписи 11 sp, ripple-ограниченный круг 48 dp, семантика `Role.Tab`, скрытие при IME и во вложенных экранах с анимацией slide/fade 200 мс, `NavigationRail` при ширине ≥ 600 dp.

### Концепция 1 — «Hairline Minimal»
Чистый чёрный фон = фон экрана, только верхняя линия `#1F1F1F`. Активная вкладка: иконка в заполненном варианте + подпись SemiBold белая; неактивные — контурные `#8E8E93`. Под активной иконкой точка 4 dp, переезжает с анимацией `spring`.
- Плюсы: максимально близко к текущему Fusion, минимум изменений. Минусы: точка — мелкий акцент.

### Концепция 2 — «Pill Indicator»
Как M3, но монохромно: за активной иконкой капсула 56×32 dp `#1C1C1E` (Graphite: `#2A2A2D`), анимированно растягивается при переключении; подписи только у активной вкладки (остальные — иконки) либо у всех — настраивается в «Кастомизации».
- Плюсы: самый понятный активный state, хорошая доступность. Минусы: чуть «тяжелее» визуально.

### Концепция 3 — «Floating Dock»
Плавающая капсула над контентом: отступ 12 dp от краёв и от жестовой полосы, радиус 28 dp, фон `#0E0E0F` с 1 dp обводкой `#222`, без подписей (подпись всплывает у активной). Скрывается при прокрутке вниз, появляется при прокрутке вверх.
- Плюсы: современно, освобождает высоту, хорошо на 120 Гц. Минусы: перекрывает последний элемент списка (нужен `contentPadding`), сложнее с insets и клавиатурой.

### Концепция 4 (опция) — «3 раздела»
Объединить «Настройки» и «Профиль» в одну вкладку (профиль-шапка + настройки, как в Telegram), панель: «Контакты/Звонки · Чаты · Настройки». Снижает дублирование; совместима с любой из концепций 1–3.

Рекомендация к обсуждению: **Концепция 2 или 1 + Концепция 4**.

## 3. Критерии приёмки после реализации
- Одинаковая высота и вид во всех режимах; на 3-кнопочной и жестовой навигации фон заполнен до низа экрана.
- Нет боковых рамок; hairline только сверху.
- Ripple/press-state на каждом пункте; TalkBack: «Чаты, вкладка, выбрана, 2 из 4».
- Клавиатура не перекрывает поля ввода; панель не «прыгает» над клавиатурой.
- Выбранный раздел сохраняется при повороте и при восстановлении процесса.
- Скриншот-тесты: 360×640, 412×915, 600 dp ландшафт, шрифт 130%.
