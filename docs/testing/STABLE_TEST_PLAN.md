# KiroX 1.0.0 — полный тест перед стабильной версией

Сборка: release, подписана ключом KiroX. Телефон: Android 10–17, arm64.
Тестовый собеседник — свой второй аккаунт («Киря»). На основном аккаунте не завершать сеансы, не удалять чаты и не менять приватность без необходимости.

Отметки: ✅ работает · ❌ ошибка (описать) · ⏭ пропущено.
Автоматически перед тестом: юнит-тесты 35/35, lint 0 ошибок.
