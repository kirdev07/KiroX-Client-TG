# KiroX Fusion UI — группы, каналы, форумные темы и папки

**Статус:** DRAFT / НА СОГЛАСОВАНИИ (29.10.2026). Это **визуальный дизайн**, а не готовые Android/TDLib-функции.
**Ветка:** `design/kirox-fusion-expressive-glass` (только документация, `main` не затронут).
**Визуальная основа:** утверждённые пользователем фиолетовый Fusion Expressive и сине-стеклянный Fusion Glass; новая концептуальная картинка этого блока показана в беседе ChatGPT 29.10.2026. Сам PNG пока не хранится в GitHub: Claude Code должен получить точный пользовательский эталон как отдельный файл для сравнения.

## 16 макетов: 8 композиций × 2 стилистики

| № | Экран | Компоновка и смысл |
|---|---|---|
| 1 | **Список чатов / группы и папки** | Заголовок «Чаты», поиск, чипы «Все», «Личные», «Группы», «Каналы», «Папки», далее архив и реальные чаты, внизу утверждённый док |
| 2 | **Информация о группе** | Обложка/аватар, название, количество участников, быстрые действия, описание, ссылка, вкладки «Участники / Медиа / Файлы / Ссылки» |
| 3 | **Создание группы** | Фото, название, описание, выбор участников; после проверки полномочий/поддержки — подтверждение создания и настройки группы |
| 4 | **Форумные темы** | Шапка группы, «Чаты / Темы / Участники», поиск по темам, список тем с индикаторами непрочитанного, создание темы только при соответствующих правах |
| 5 | **Создание канала** | Аватар, название, описание, публичность/частный доступ, ссылка при допустимости, кнопка создания |
| 6 | **Просмотр канала** | Заголовок, закреплённое сообщение, лента постов с медиа и реакциями, комментарии при реальной связанной группе |
| 7 | **Папки чатов** | Список реальных папок и системных разделов; добавление, порядок, включение/исключение чатов, счётчики, настройки |
| 8 | **Редактирование папки** | Имя/иконка, выбранные чаты, добавить/убрать, порядок, сохранить, отмена/удаление с подтверждением |

### Внешний вид для обоих стилей

- **Fusion Expressive:** тёмный AMOLED, яркий фиолетовый `#A276FF`, глубокие `#141121` и `#211B31`, выразительные округлые Material 3 Expressive формы. Акцент у активных чипов, кнопок создания и счётчиков. Переписка и списки остаются читабельными.
- **Fusion Glass:** navy `#071424`, голубой `#6B91FF`, границы сине-серого стекла и ограниченное размытие фоновых подложек. Фоновые иллюстрации не мешают чтению; на слабых устройствах непрозрачный fallback без blur.
- Сохранять согласованные компоненты, иконки и переходы, не изобретать другое расположение вкладок. Размер интерактивных целей от 48dp, уважать размер системного шрифта, Android insets, жесты Back/IME, настройки Reduce Motion.
- Плавная подгрузка списков и сохранение положения скролла, без тяжёлого размытия каждого динамического элемента.

## Поведение — только реальные Telegram-данные

**Группы:**
- Участники, роли, описание и ссылки — только из TDLib. Список участников может быть ограничен сервером и приватностью.
- Создание, редактирование группы, приглашения, администрирование и права доступны только если Telegram и текущий пользователь позволяют. Нельзя скрывать отказ API под фиктивным успехом.
- Для каналов отличать права подписчика от прав администратора; «Создать пост»/«Изменить» показывать только по реальным правам.
- Подписи «Telegram Premium», верификация, просмотры, реакции, статистика — только из настоящих полей; никаких выдуманных значков или счётчиков.

**Темы:**
- Форумные темы не равны обычным папкам или независимым чатам. Для каждой темы использовать соответствующие TDLib thread/topic IDs; не смешивать идентификаторы сообщений.
- Отображать тему «Общие» и уведомления, если реальные данные их поддерживают. Нет доступной темы — корректное пустое состояние.
- Поиск, закрепление, создание/закрытие темы и переходы зависят от состояния и полномочий.

**Папки:**
- Текущий код уже содержит `FolderDialogs.kt` с созданием/удалением папок и `ChatLists.kt` с отдельным `ChatListFolder`. Прежде чем менять UI, Claude должен проверить их реальную работу и интеграцию.
- Поддерживать полноценные фильтры TDLib там, где реализованы: выбранные/исключённые чаты, типы, порядок, закреплённые, архив отдельно от пользовательских папок.
- Не подменять системный архив папкой; не применять изменения папок других аккаунтов.
- Удаление/изменение с подтверждением/отменой, предотвращением потери выбора.

## Известный конфликт навигации

В утверждённых концептах нижний док показан `Чаты / Звонки / Истории / Настройки`. Текущий Android-код ранее содержал `Контакты / Чаты / Настройки / Профиль`. Прежде чем менять корневые маршруты, предоставить карту миграции с сохраняющимся доступом к контактам, своему профилю, аккаунтам, папкам, каналам и группам. Дизайн сам по себе не разрешает незаметно отключать функции.

## Безопасность и производительность

- Реальные данные TDLib вместо моков в авторизованном аккаунте; отдельный preview/mock допускается только для дизайна без серверных действий.
- Никогда не копировать исходники/ресурсы Yougram; референс — только качество интерфейса.
- Обязательные состояния: загрузка, пусто, офлайн, ограничение доступа, недостаточно прав, ошибка создания, удалённая/недоступная тема, лимиты папок.
- Проверить долгие списки, 360dp/412dp/планшет, 130–200% масштаб шрифтов, 3-кнопочную/жестовую навигацию.
- Анимация и blur не должны приводить к избыточным рекомпозициям или тормозам.
