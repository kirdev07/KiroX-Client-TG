# KiroX — Media Studio: медиа, вложения, GIF и стикеры

**Статус:** VISUALLY APPROVED — одобрено владельцем 29 октября 2026 для обоих стилей. Разработка и интеграционные тесты пока не выполнены.
**Визуальная основа:** утверждённые Fusion Expressive и Fusion Glass; та же навигация и общий язык интерфейса. Визуальная композиция Media Studio утверждена в двух стилях.
**Ветка:** `design/kirox-fusion-expressive-glass`. Ветка main и реальная Telegram-интеграция в рамках этих документов не меняются.

## Целевые сценарии (8 × 2 темы)

Визуальный лист включает 8 экранов в каждом стиле. Ниже шесть базовых функциональных компонентов плюс два явно выделенных варианта — вложения непосредственно в переписке и выбор файлов. Сохранить их расположение из утверждённого визуального листа.

### 1. Fullscreen Photo Viewer
- Фото на чёрном или адаптивном тёмном фоне без обрезки; двойной тап zoom, pinch zoom, свайп к соседним медиа.
- Сверху назад, автор/дата и меню; снизу подпись, счётчик, сохранить/поделиться/переслать при фактической доступности.
- Одно касание скрывает хром интерфейса; система Back возвращает в исходный чат с сохранённой позицией.

### 2. Video Player
- Видео занимает доступную площадь с сохранением aspect ratio. Play/pause, таймлайн, время, звук, полноэкранный режим, скорость при поддержке.
- Запомнить прогресс лишь там, где уместно; не держать decode/blur в фоне после закрытия.
- Не ставить фальшивый play поверх неработающего плеера. Состояния buffering, offline, download error.

### 3. Attachment Bottom Sheet
- Поверх переписки: фото, видео, файл, контакт, геолокация, музыка и опрос *только при поддержке соответствующих TDLib действий*.
- Контент чата остаётся в фоне. Expressive — графитовые карточки с фиолетовыми активными состояниями; Glass — синяя полупрозрачная поверхность с умеренным blur.
- Клавиатура/IME и жест сворачивания не конфликтуют с системной навигацией; Android Photo Picker предпочтительнее лишних разрешений.

### 4. Sticker / Emoji Picker
- Табы Emoji, Стикеры, GIF; быстрый поиск, недавно использованные, избранные, пакеты. Опции соответствуют реально доступным данным Telegram.
- В обеих темах размер ячеек и положение табов одинаковы; активный индикатор отражает тему. Превью стикера — long press, без ложной отправки.
- Для премиум-эмодзи показывать только фактическую доступность Telegram, не симулировать Premium.

### 5. GIF Explorer
- Поиск и сетка GIF, предварительный просмотр и отправка по нажатию. Анимации только видимых ячеек, lifecycle pause при уходе.
- Пустое состояние и отсутствие GIF API честно обозначать. Не подгружать демонстрационный каталог вместо Telegram при живой сессии.
- Поддержка reduced motion, экономия трафика и памяти.

### 6. Media Gallery / Shared Media
- Сетка миниатюр фото и видео с длительностью, переключение Медиа/Файлы/Ссылки/Голосовые; внутри конкретного чата — реальные общие материалы.
- Множественный выбор с явными действиями и отменой. Избегать дублирования логики списка чатов и профилей.

### 7. Вложения непосредственно в чате
- Встроенные превью фото, альбомов и документов среди реальных сообщений; мини-плеер голосовых и привычное поле ввода снизу.
- Никакой отдельной «псевдо-ленты»: данные привязаны к идентификаторам сообщений и состояний TDLib, сохраняют ответы, редактирование и доступность.

### 8. Выбор файлов
- Отдельный экран или системный picker для документов, архивов, презентаций, музыки и видео; категории «Все / Документы / Архивы / Другое» только при наличии реального источника.
- Учитывать Android Storage Access Framework и выбранные пользователем разрешения, не запрашивать широкий доступ к хранилищу без необходимости.
- Отображать размер/тип, процесс отправки и ошибку, не подменять реальные файлы примерами из макета.

## Стиль — обязательная согласованность

**Fusion Expressive:** глубокий AMOLED, графитово-фиолетовые поверхности, яркие purple/violet интеракции, округлые M3 Expressive кнопки, полупрозрачная тёмная подложка над контентом. Никакого постороннего радужного дизайна.

**Fusion Glass:** navy, атмосферные сине-фиолетовые поверхности, стеклянные dock/toolbar/sheet, мягкое голубое свечение; опциональный blur на небольших панелях, fallback без blur на слабых устройствах.

Общие правила: токены из `theme-tokens.json`, минимум 48dp на интерактивные цели, качественная типографика и контраст, темп переходов 120–300мс, Android Back/gestures/insets, без ломания TDLib.

3. Разделить UI/MediaState/TDLib bridge без дублирования между двумя стилями. Переиспользовать существующие компоненты и settings.
4. Проверить фото и видео с разными форматами и ориентацией, многомегабайтные файлы, медленную сеть, незавершённые загрузки, выход из экрана и память GPU.
5. Контроль сессии и приватности; не загружать незапрошенные файлы и не смешивать аккаунты.
6. Отчёт с APK, screenshot-диффами, тестами PASSED/FAILED/NOT TESTED и затем остановка перед merge.
