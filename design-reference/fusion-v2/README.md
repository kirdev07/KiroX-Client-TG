# KiroX Fusion UI — утверждённая дизайн-система

**Согласовано владельцем:** 29 октября 2026.  
**2 оформления:** Fusion Expressive (фиолетовый Material 3 Expressive) и Fusion Glass (сине-стеклянный).  
**Масштаб:** 46 согласованных визуальных композиций в каждом стиле, **92 варианта всего**. Повторяющиеся сценарии объединяются в общие Android-экраны.  
**Стадия:** **только дизайн, спецификации и подготовка для Claude Code**; на этой ветке ещё нет новой реализации Compose/TDLib и нет результатов её сборки.  
**Рабочая ветка:** `design/kirox-fusion-expressive-glass`. `main` не затронут.  
**Проверенная версия исходников:** KiroX 1.0.0-rc.1 по `app/build.gradle.kts` (на момент аудита 29.10.2026).

## Главное — сохранить утверждённый визуальный образ

- Использовать **точные изображения, которые владелец утвердил в беседе**. Бинарные PNG не находятся в GitHub и должны быть отдельно предоставлены Claude Code для пиксельного сравнения. Не заменять их новыми AI-изображениями.
- Не менять расположение понравившихся панелей, чатов, историй, нижнего dock, кнопок ввода и настроек.
- Цвет **нужен**: не превращать оба варианта обратно в чёрно-белый интерфейс.
- Утверждённый визуальный dock — `Чаты · Звонки · Истории · Настройки`; текущий код содержит другую структуру. Перед изменением требуется карта переходов без потери Контактов, Профиля и аккаунтов.
- Реальный TDLib, существующий VoIP, чат-репозитории, авторизация, обработка ошибок и настройки должны оставаться рабочими. Не имитировать выдуманную подписку, Premium или результат вызова.
- Не копировать чужой код/ресурсы Yougram: дизайн используется только как визуальный ориентир.
